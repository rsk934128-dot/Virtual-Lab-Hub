# 🚀 Virtual Lab Hub (ভার্চুয়াল ল্যাব হাব)
### *Advanced Android Virtual Container & Cloud Development Sandbox*

---

## 📖 প্রজেক্ট পরিচিতি (Introduction)
**Virtual Lab Hub** হলো একটি শক্তিশালী, আধুনিক এবং সুরক্ষিত **'User-Space Containerized Android & Linux Testing Environment'**। এটি কোনো ধরনের সিস্টেম মোডিফিকেশন বা ফোনের ক্ষতি ছাড়াই আপনার সাধারণ অ্যান্ড্রয়েড ফোনের ভেতরেই একটি সম্পূর্ণ সুরক্ষিত ভার্চুয়াল সিস্টেম, ক্লাউড ড্যাশবোর্ড এবং রিয়েল-টাইম প্যাকেজ ম্যানেজার প্রদান করে।

---

## ✨ বর্তমান ফিচার ও কার্যক্ষমতা (Current Features & Capabilities)

### ১. 📂 জিপ অ্যাপ অটো-এক্সট্রাক্টর ও লাইভ প্লেয়ার (Live ZIP App Runner)
* **সরাসরি জিপ ফাইল রান:** যেকোনো জিপ আর্কাইভ (যেমন: `Rubel-Video-Audio-Downloader-main.zip` বা যেকোনো ওয়েব/ক্যাপাসিটর অ্যাপ) অ্যাপের ভেতর আপলোড করলেই তা স্বয়ংক্রিয়ভাবে এক্সট্রাক্ট হয়ে লাইভ রান করে।
* **ফুলস্ক্রিন লাইভ স্যান্ডবক্স:** জাভাস্ক্রিপ্ট, ডোম স্টোরেজ, লোকাল ফাইল ক্যাশ এবং ব্যাক ন্যাভিগেশন সমর্থনকারী অপ্টিমাইজড রানটাইম।
* **প্রি-ইন্টিগ্রেটেড অ্যাপ:** রুবল ভিডিও ও অডিও ডাউনলোডার এক ক্লিকে অফলাইনেও লাইভ চালানোর সুবিধা।

### ২. 📱 ভার্চুয়াল অ্যান্ড্রয়েড ও লিনাক্স প্রোফাইল ম্যানেজার (Virtual Environment Manager)
* **একাধিক ওএস প্রোফাইল:** 
  - `Android 14 (AOSP User-space)` - 2048 MB vRAM, 16 GB ভার্চুয়াল স্টোরেজ।
  - `Android 12 (Lite Container)` - 1024 MB vRAM, 8 GB ভার্চুয়াল স্টোরেজ।
  - `Alpine Linux Minimal` - 1024 MB vRAM, হেডলেস টার্মিনাল মোড।
* **সিস্টেম স্টেট কন্ট্রোল:** ভার্চুয়াল সিস্টেমগুলো ইচ্ছামতো **Launch (চালু)** বা **Suspend (সাময়িক স্থগিত)** করার সুযোগ।
* **ভার্চুয়াল অ্যাপ স্টোর:** ভার্চুয়াল সিস্টেমের ভেতর আলাদা আলাদা টেস্ট অ্যাপ (Terminal, Network Analyzer, Disk I/O Benchmark) ইন্সটল এবং রিমুভ করার সুবিধা।

### ৩. 📊 রিয়েল-টাইম রিসোর্স টেলিমেট্রি (Virtual Resource Monitor)
* **vCPU লোড মনিটরিং:** ডিভাইসের সিপিইউ কোর ও সক্রিয় ভার্চুয়াল কনটেইনারের প্রসেস ট্র্যাক করে লাইভ লোড পারসেন্টেজ প্রদর্শন।
* **ভার্চুয়াল র‍্যাম (RAM) ট্র্যাকিং:** মেমোরি হিপ এবং ব্যবহৃত র‍্যামের সঠিক পরিসংখ্যান।
* **স্যান্ডবক্স ডিস্ক স্টোরেজ:** ভার্চুয়াল কনটেইনারের ব্যবহৃত স্টোরেজ এবং ডিভাইসের খালি জায়গার লাইভ হিসেব।

### ৪. 🌐 পিডব্লিউএ বিল্ডার ও টিডব্লিউএ প্যাকেজিং (PWABuilder Android Workbench)
* **ওয়েব অ্যাপ ম্যানিফেস্ট অ্যানালাইজার:** যেকোনো ওয়েব অ্যাপ্লিকেশন বা PWA URL দিলে তা অটোমেটিক অ্যানালাইজ করে।
* **Trusted Web Activity (TWA) সিন্থেসিস:** ওয়েব অ্যাপকে তাৎক্ষণিক নেটিভ অ্যান্ড্রয়েড প্যাকেজে রূপান্তর।
* **এক ক্লিকে স্যান্ডবক্সে টেস্ট রান:** রূপান্তরিত PWA অ্যাপটিকে ভার্চুয়াল অ্যান্ড্রয়েড সিস্টেমে ইন্সটল করে সরাসরি টেস্ট করার সুবিধা।

### ৫. ☁️ ভারসেল ক্লাউড হোস্টিং (Vercel Cloud Integration)
* **ইনস্ট্যান্ট এজ ডেপ্লয়মেন্ট:** Next.js, React, Node.js ফুলস্ট্যাক প্রজেক্টের লাইভ ভারসেল ইউআরএল তৈরি।
* **ওয়ান-ট্যাপ কপি ও ভার্চুয়াল লিঙ্ক:** তৈরি করা প্রজেক্ট এক ট্যাপে কপি করে ভার্চুয়াল ল্যাবের প্যাকেজ ক্যাটালগে যুক্ত করা।

### ৬. 🐧 লিনাক্স প্যাকেজ ওয়ার্কবেঞ্চ (Linux Package Workbench)
* **প্যাকেজ কমান্ড গাইড:** `apt update`, `apt upgrade` এবং `apt full-upgrade`-এর মধ্যে পার্থক্য এবং রিয়েল-টাইম টার্মিনাল সিমুলেশন।
* **লাইভ টার্মিনাল কনসোল:** কমান্ড চালিয়ে রিয়েল-টাইম আউটপুট দেখার ব্যবস্থা।

### ৭. 🛡️ ক্লাউড ডেটাবেজ ও এন্টারপ্রাইজ সিকিউরিটি (Firebase & Security)
* **ক্লাউড ফায়ারস্টোর (Firestore):** ব্যবহারকারীর স্যান্ডবক্স সেশন এবং প্রোফাইল সম্পূর্ণ ক্লাউডে সিঙ্ক থাকে।
* **গুগল সাইন-ইন (Jetpack Credential Manager):** নিরাপদ এবং আধুনিক প্রমাণীকরণ ব্যবস্থা।
* **জিরো-ট্রাস্ট সিকিউরিটি রুলস:** ব্যবহারকারীর নিজস্ব ডেটা কেবল তিনিই দেখতে পাবেন।
* **এনভায়রনমেন্ট আইসোলেশন পলিসি:** সেটিংস থেকে নেটওয়ার্ক আইসোলেশন এবং এক্সটার্নাল স্টোরেজ এক্সেস নিয়ন্ত্রণ করার সুবিধা।

## 🛠️ প্রযুক্তিগত স্ট্যাক (Technology Stack)

* **Programming Language:** 100% Kotlin
* **UI Framework:** Jetpack Compose (Material Design 3)
* **Architecture:** Clean Architecture & MVVM (StateFlow, Coroutines)
* **Backend & Cloud:** Firebase Firestore, Firebase Authentication
* **Security & Auth:** Jetpack Credential Manager (Google Sign-In)
* **Container Core:** User-Space Workspace (`VirtualCore.kt`)
* **Live Sandbox Engine:** Android WebKit Isolated Engine (`ZipAppRunner.kt`)
* **Testing:** Robolectric JVM Integration Tests & JavaScript Rules Test
